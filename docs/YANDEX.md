# Яндекс Игры: как выложить

## Сборка

```bash
npm run build:yandex
```

Получится `game-yandex.zip` (index.html в корне). Его загружают в консоли разработчика:
https://games.yandex.ru/console → «Добавить приложение» → вкладка «Черновик» → «Архив с игрой».

Сборка для Яндекса отличается от сайта: подключает SDK (`/sdk.js`), без «Установить на телефон» и без service worker.
Код — `src/platform.js` (SDK), `src/platform-hooks.js` (кнопки в игре).

## Что уже сделано в игре

| Требование / доход | Где |
|---|---|
| `LoadingAPI.ready()` — игра загрузилась | при показе главного меню |
| `GameplayAPI.start()/stop()` — разметка геймплея | каждый кадр: идёт заезд → start, пауза/итоги/меню → stop |
| пауза и звук на время рекламы, `game_api_pause/resume` | заезд — на паузу, вся музыка и звуки стоят |
| 🎬 реклама за награду: «Второй шанс» | плашка «РАЗБИЛСЯ!» — «Дальше за рекламу», раз за забег, отсчёт стоит во время ролика |
| 🎬 реклама за награду: ×2 «Е» | итоги забега — «×2 «Е» за рекламу +N Е» |
| межэкранная реклама | по «Повторить» / «В меню» на итогах, с 3-го заезда сессии, не чаще раза в 3 минуты; после покупки «Без рекламы» — нет |
| покупки, «Касса» | витрина машин, внизу; цена и иконка валюты — из каталога Яндекса |
| незачисленные покупки | при запуске `getPurchases()` → начислить → `consumePurchase()`; «Без рекламы» восстанавливается на новом устройстве |

Проверить без Яндекса: открыть игру с `?ads=mock` — тестовая реклама (чёрная плашка на 1.5 с) и тестовые покупки.

## Настроить в консоли (один раз)

1. **Покупки** — включить «Внутриигровые покупки» и завести товары с ТАКИМИ id:

   | id | название | цена (предложение) |
   |---|---|---|
   | `vhs10` | 10 кассет | 29 ЯН |
   | `vhs50` | 50 кассет | 99 ЯН |
   | `e30k` | 30 000 «Е» | 49 ЯН |
   | `noads` | Без рекламы между заездами | 149 ЯН |

   (Покупки доступны после модерации и подписания договора в разделе «Монетизация».)
2. **Реклама** — включается сама после публикации; в «Монетизации» заполнить реквизиты.
3. **Описание, иконка 512×512, обложка 800×470, скриншоты** (телефон и компьютер), возраст 6+.
4. Языки: русский (английский можно добавить позже — интерфейс уже переводится, src/i18n.js).

## На модерации проверяют (наш статус)

- ✅ нет ссылок на сторонние сайты и чужой рекламы;
- ✅ звук выключается при сворачивании и во время рекламы;
- ✅ игра не ломается без сети (таблица рекордов и облако — по возможности);
- ✅ реклама не появляется во время заезда;
- ⚠ «Код сохранения» (облако Supabase) — на Яндексе позже лучше заменить на сохранение в аккаунт Яндекса (`player.setData`): игрок не теряет прогресс, а модераторы это любят.
