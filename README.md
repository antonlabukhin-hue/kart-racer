# 🏎️ Дорожный прорыв (kart-racer)

Аркадные 3D-гонки на [Three.js](https://threejs.org/): пост-апокалиптичные трассы Приморья, советские тачки, звери на дороге и мини-боссы в кампании.

**Играть онлайн:** [antonlabukhin-hue.github.io/kart-racer](https://antonlabukhin-hue.github.io/kart-racer/)

## Об игре

- **Кампания** — цепочка трасс до исследовательского центра, свой мини-босс на главу  
- **Одиночный заезд** — выбор карты, погоды (день / ночь / дождь) и сложности  
- **Гараж и магазин** — Чебурашка, Нива, Волга; цвет и тюнинг  
- **Профили** — прогресс, фишки, ачивки и трофеи в `localStorage`  
- **Мобайл** — сенсорное управление, адаптивный HUD  

Сеттинг: лихие 90-е / постапок, звери перебегают дорогу, на трассе — нитро, жвачка «Турбо», масло и кочки.

## Быстрый старт

### Вариант A — просто открыть

1. Скачай репозиторий  
2. Открой корневой `index.html` в браузере  
   (удобнее через локальный сервер, см. ниже)

### Вариант B — Vite (рекомендуется)

```bash
git clone https://github.com/antonlabukhin-hue/kart-racer.git
cd kart-racer
npm install
npm run dev
```

Сборка продакшена:

```bash
npm run build    # → папка dist/
npm run preview  # локальный просмотр сборки
```

**Требования:** Node.js 18+, современный браузер с WebGL.

## Структура репозитория

```text
kart-racer/
├── index.html          # основной билд игры (монолит + Three.js)
├── src/main.js         # точка входа для Vite (если используется)
├── images/             # меню, карты, трофеи, спрайты машин
├── music/              # menu-music.mp3, race-music.mp3
├── dist/               # production-сборка Vite
├── package.json        # three, vite
└── README.md
```

Ассеты (`images/`, `music/`) должны лежать рядом с `index.html`, иначе в консоли будут CORS/404 (особенно в `file://` и песочницах).

## Стек

| | |
|--|--|
| 3D | [Three.js](https://threejs.org/) `^0.185` |
| Сборка | [Vite](https://vitejs.dev/) `^8.2` |
| Аудио | Web Audio API (двигатель, SFX) + HTML5 Audio (музыка) |
| Сохранения | `localStorage` (профили, кампания, гараж) |

Внешних серверов и аккаунтов нет — всё работает офлайн после загрузки.

## Режимы и контент

- **Карты:** Арсеньев, Промзона, Свалка и др.  
- **Машины:** Чебурашка (старт), Нива, Волга  
- **Сложность:** лёгкая / средняя / сложная  
- **Качество графики:** low / medium / high (тени, плотность декора)  

Прогресс кампании и гаража привязан к **имени профиля** на устройстве.

## Известные ограничения

- В sandbox / `about:srcdoc` музыка и картинки с чужого origin могут блокироваться CORS — открывай через GitHub Pages или `npm run dev`.  
- Процедурная музыка включается, если MP3 недоступен.  
- Мультиплеер в меню — заглушка («в разработке»).

## Разработка

Имеет смысл править один «источник правды» (корневой `index.html` *или* модули под Vite) и не плодить расхождения. Перед пушем:

```bash
npm run build
# проверить dist/ локально через npm run preview
```

Коммиты лучше с коротким смыслом: `fix: traffic maxCars in campaign`, `perf: compress menu JPEGs`.
