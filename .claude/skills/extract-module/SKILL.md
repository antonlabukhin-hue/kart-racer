# Вынос логики из main.js в модуль

`tests/unit/architecture.test.js` — «трещотка»: `MAX_MAIN_LINES` и `MAX_MAIN_WINDOW_GLOBALS` могут только уменьшаться.

## 1. Выбрать кусок
- Grep по имени функции в `src/main.js`, читать только окрестность (файл ~11.6k строк — целиком не читать).
- Хорошие кандидаты: чистые вычисления (очки, награды, таймеры, выбор/рандом, форматирование текста), таблицы данных, разметка экранов без игрового состояния.
- Плохие: код, завязанный на десятки локальных переменных `initGame` (`track`, `car`, `scene`…) — сначала выделить из него чистое ядро.
- Проверить, нет ли уже подходящего модуля (таблица в `src/ARCHITECTURE.md`) — дописать туда, а не плодить новый.

## 2. Модуль `src/<имя>.js`
- ESM, именованные экспорты, без `window.*` и без DOM, если можно. Состояние — параметрами и возвращаемыми значениями.
- Экраны меню — в `src/ui/`, зависимости передаются явно (тест запрещает там `window.__*`).
- Данные трасс/машин/зверей — в `src/data.js`, мета-контент — `src/content.js`, тексты — через `src/locales/`.

## 3. Подключение в main.js
- Импорт в шапке. **TDZ:** имя импорта не должно совпадать с локальными `const` внутри `initGame` (`track` и др.) — при совпадении переименовать импорт (`import { track as trackEvent }`).
- Функции из `onclick=` в разметке оставить на `window` (обёрткой).
- Не дописывать `// комментарий` в середину длинной строки с несколькими операторами — только `/* */` или в конец.

## 4. Тест `tests/unit/<имя>.test.js`
- vitest, по образцу соседних тестов (`describe`/`it`/`expect`, названия по-русски).
- Покрыть граничные случаи, ради которых логика существует (нули, пустые списки, максимум, смена дня и т.п.).

## 5. Трещотка и документация
1. `npm run test:unit` — architecture-тест подскажет новое число строк («порог можно снизить до N»).
2. Опустить `MAX_MAIN_LINES` (и `MAX_MAIN_WINDOW_GLOBALS`, если убавились) до фактических значений.
3. Добавить строку в таблицу `src/ARCHITECTURE.md`.
4. Если затронут видимый UI — скилл `visual-check`.

## 6. Коммит
Отдельный коммит `refactor(<область>): <что вынесено> в <модуль>.js` по-русски.
